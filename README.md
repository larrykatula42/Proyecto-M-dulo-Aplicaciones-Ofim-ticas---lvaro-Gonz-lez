# Proyecto-M-dulo-Aplicaciones-Ofim-ticas---lvaro-Gonz-lez
Módulo 0223 — Aplicaciones Ofimáticas

Proyecto Intermodular · 1.º SMR · Curso 2025–2026

¿De qué trata este módulo?

Este módulo forma parte del Proyecto Intermodular del Ciclo Formativo de Grado Medio en Sistemas Microinformáticos y Redes (SMR). Está elaborado dentro del módulo de Aplicaciones Ofimáticas (código 0223) de 1.º curso.

El objetivo es aplicar los conocimientos de ofimática (Word, Excel y PowerPoint) para crear documentación real y útil para una pequeña empresa. La empresa utilizada como referencia es TechOficina S.L., una empresa simulada que ofrece servicios informáticos a pequeños negocios de Madrid.

La empresa: TechOficina S.L.

TechOficina S.L. es una microempresa de 6 empleados dedicada al soporte y mantenimiento informático para pequeñas empresas que no disponen de departamento TI propio.

La empresa cuenta con:

Ordenadores de sobremesa y portátiles
Servidor NAS
Red local con switch y router
Suite Microsoft 365 como entorno principal de trabajo
Documentos creados
1. 01_Descripcion_Empresa.docx — Documento descriptivo

Tipo: Documento Word (.docx)

¿Qué es?

Documento formal que describe la empresa de manera completa. Incluye:

Portada
Índice
Identificación de la empresa
Actividad principal
Personal y puestos de trabajo
Infraestructura informática
Objetivos del sistema informático
¿Para qué sirve?

Actúa como documento base del proyecto. Permite comprender qué hace la empresa, cómo trabaja y qué recursos tecnológicos utiliza.

Formato
Diseño profesional
Encabezado y pie de página
Tablas y listas
Estilos de títulos y secciones
2. 02_Inventario_Equipos.xlsx — Inventario de hardware y software

Tipo: Hoja de cálculo Excel (.xlsx)

¿Qué es?

Libro de Excel compuesto por tres hojas:

Hardware

Inventario de equipos físicos de la empresa:

Ordenadores
Portátiles
Servidor
Impresora
Otros dispositivos

Cada registro incluye usuario asignado, ubicación, sistema operativo y software instalado.

Software

Relación de licencias y programas utilizados por la empresa, indicando:

Tipo de licencia
Equipos donde está instalado
Resumen

Resumen automático del número total de equipos por categoría.

¿Para qué sirve?

Permite gestionar y controlar todos los activos informáticos de la empresa de forma organizada.

Es una herramienta útil para tareas de mantenimiento, soporte técnico y seguimiento del equipamiento.

Columnas principales (Hardware)
ID de equipo
Tipo
Marca / Modelo
Usuario
Ubicación
Sistema operativo
Software principal
Observaciones
3. 03_Registro_Incidencias.xlsx — Registro de incidencias técnicas

Tipo: Hoja de cálculo Excel (.xlsx)

¿Qué es?

Libro de Excel formado por tres hojas:

Incidencias

Tabla principal donde se registran los problemas técnicos detectados.

Incluye 10 incidencias de ejemplo realistas.

Resumen

Cuenta automáticamente las incidencias según su estado:

Resuelto
En proceso
Pendiente
Plantilla

Ficha vacía preparada para registrar nuevas incidencias.

¿Para qué sirve?

Permite realizar el seguimiento de problemas informáticos y documentar:

Qué ocurrió
Cómo se resolvió
Quién lo solucionó
Estado actual de la incidencia

Es una herramienta básica en cualquier entorno de soporte técnico.

Columnas principales
Nº
Fecha de apertura
Fecha de cierre
Equipo
Usuario
Descripción
Solución
Técnico
Prioridad
Estado
4. 04_Presentacion_Sistema_Informatico.pptx — Presentación PowerPoint

Tipo: Presentación PowerPoint (.pptx)

¿Qué es?

Presentación de 7 diapositivas con diseño visual profesional que explica el sistema informático de la empresa de forma clara y visual.

Contenido de las diapositivas
Nº	Contenido
1	Portada con datos del proyecto
2	Descripción de la empresa y servicios
3	Equipos informáticos principales
4	Diagrama de red
5	Sistemas operativos y software
6	Ventajas de la solución propuesta
7	Cierre y datos de contacto
¿Para qué sirve?

Permite presentar el proyecto de forma profesional ante el profesor o el resto de la clase.

También simula una presentación técnica orientada a clientes.
